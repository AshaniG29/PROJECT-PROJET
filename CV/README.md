# PROJECT-PROJET

Ce projet contient mes travaux réalisés en HTML et CSS.

## 🚀 Objectif
Visualiser le rendu final du projet en ouvrant le fichier HTML.

## 🔧 Instructions
Pour voir le rendu :
1. Télécharger ou cloner le projet
2. Ouvrir le fichier `index.html`
3. Cliquer droit → **Ouvrir avec** → **Firefox**

- `style.css` : mise en forme
